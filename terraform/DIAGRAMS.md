## Traffic Flow Diagrams

### Public Subnet Traffic Flow

```
┌──────────────┐                    ┌──────────────────┐
│              │                    │                  │
│   Internet   │◄──────────────────►│ Internet Gateway │
│              │                    │                  │
└──────────────┘                    └─────────┬────────┘
                                              │
                                              ▼
                                    ┌──────────────────┐
                                    │  Public Subnet   │
                                    │                  │
                                    │  • Web Servers   │
                                    │  • NAT Gateway   │
                                    │  • Load Balancer │
                                    └──────────────────┘
```

### Private Subnet Traffic Flow (Outbound)

```
┌──────────────┐       ┌─────────────┐       ┌──────────────────┐       ┌──────────────────┐
│  Private     │       │             │       │                  │       │                  │
│  Subnet      │──────►│ NAT Gateway │──────►│ Internet Gateway │──────►│    Internet      │
│              │       │  (Public)   │       │                  │       │                  │
└──────────────┘       └─────────────┘       └──────────────────┘       └──────────────────┘
```

### Inter-Subnet Communication

```
┌──────────────┐                    ┌──────────────────┐
│              │                    │                  │
│    Public    │◄──────────────────►│     Private      │
│   Subnet     │   Security Group   │     Subnet       │
│              │      Rules         │                  │
└──────────────┘                    └──────────────────┘
```

## Resource Dependency Graph

```
VPC
 ├─► Internet Gateway
 │    └─► Public Route Table
 │         └─► Public Subnet 1, 2
 │              └─► NAT Gateway (in Public Subnet 1)
 │                   └─► Private Route Table
 │                        └─► Private Subnet 1, 2
 │
 ├─► Security Group - Web
 │    └─► Security Group Rules (HTTP, HTTPS, SSH)
 │
 └─► Security Group - Database
      └─► Security Group Rules (MySQL, PostgreSQL from Web SG)
```
