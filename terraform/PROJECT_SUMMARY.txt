PROJECT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A complete Terraform infrastructure deployment across three AWS regions in Asia:
• Singapore (ap-southeast-1)
• South Korea (ap-northeast-2)  
• Japan (ap-northeast-1)

Based on AWS Route53 Geolocation Routing Policy architecture.

DEPLOYMENT STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Configure AWS credentials
2. Navigate to terraform/ directory
3. Run: terraform init
4. Run: terraform plan (review changes)
5. Run: terraform apply (deploy infrastructure)
6. Save outputs for future reference
